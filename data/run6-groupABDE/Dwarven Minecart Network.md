The **Dwarven Minecart Network** is an extensive underground rail system built by the dwarves throughout the [[Asymmetrical Mountain]].

## Description
This industrial transit system consists of iron rails laid in carved stone channels, connecting key locations such as the [[Cold Forge]], mining operations, and deeper transit routes. It features switch junctions, loading platforms, maintenance bays, and hand-cranked carts for personnel transport.

## Layout
The network branches in several directions from a central junction near the forge. The eastern branch leads to mining operations, the northern branch leads toward a pump station, and a southern branch is marked for quarantine. The system was engineered for the efficient transport of ore and materials throughout the dwarven underground empire.
