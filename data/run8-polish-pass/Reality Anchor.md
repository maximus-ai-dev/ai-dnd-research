The **Reality Anchor** is a portable arcane device created by [[Cora Flint]].

## Function
When activated, the Anchor generates a stable gravitational field within a fifteen-foot radius. Within this bubble, "down" is defined as pointing toward the Anchor itself, regardless of the surrounding gravitational distortions. This makes it an essential tool for navigating unstable environments like the [[Gradient]] and for providing a fixed reference point in the zero-gravity [[Caldera]].
