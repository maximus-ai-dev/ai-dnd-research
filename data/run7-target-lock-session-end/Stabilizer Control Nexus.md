The Stabilizer Control Nexus is a control chamber within the [[Giant foundation level]] of the [[Asymmetrical Mountain]].

## Description
Built to [[Giant]] scale, this chamber contains the primary manual override interfaces for the containment field surrounding the [[Sleeper]]. The room features walls covered in crystal panels and stone interfaces, all glowing with the steady blue light of active containment magic. A massive control console, the size of a banquet table, stands at the chamber's center.

## Function
The nexus allows for the monitoring and regulation of the containment field's harmonic frequency and strength. It is part of the Giants' security measures, designed to allow for manual adjustments to the prison's systems. The chamber also contains an [[Observation Window]] providing a high vantage point into the central containment void.
